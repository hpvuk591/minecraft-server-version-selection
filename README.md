## 先定版本，再定服务端核心

Minecraft分两条完全不同的线，开服前必须先选边。

**Java版**：默认端口25565，走TCP协议。模组生态、插件生态、整合包几乎全在这边，Forge、Fabric、Paper、Mohist都是Java版的服务端。想装模组、装插件、玩整合包，只能选Java版。

**基岩版**：默认端口19132，走UDP协议。手机、平板、Win10/11自带客户端能直接进，跨平台方便，但没有Java版那套模组生态。官方服务端BDS用C++写的，Windows和Linux都有包，Linux下启动命令是`LD_LIBRARY_PATH=. ./bedrock_server`，用`screen -S mc`挂后台、`Ctrl+A+D`退出、`screen -r mc`恢复。

两边的客户端互相进不去，端口和协议也不一样。买服之前先问清楚朋友用什么客户端玩，这一步搞错，后面全白搭。

Java版的服务端核心有五种，选错了会白折腾：

| 核心 | 能装什么 | 适合谁 | 注意 |
| --- | --- | --- | --- |
| 原版（官方） | 什么都不装 | 想要原汁原味、纯净生存 | 性能一般，没优化 |
| Paper | 插件（兼容大部分Bukkit/Spigot插件） | 绝大多数生存服、插件服 | 优化最好，首选 |
| Fabric | 模组 | 追最新版本、轻量模组包 | 更新快，体量小 |
| Forge | 模组 | 传统模组整合包 | 1.21装法变了，见下 |
| Mohist | 模组+插件同时跑 | 既要模组又要插件的服 | **只更新到1.20.2**，1.21用不了 |

Mohist这一条要特别提醒。它融合了Forge和Bukkit/Spigot，能同时跑模组和插件，听起来很香，但版本停在1.20.2。你要开1.21又想要模组+插件，只能拆成两套服，或者退回1.20.2。

Forge 1.21的安装方式和老版本不同。1.16.5及以下直接跑jar就行；1.21要先执行一次安装：


java -Xms128M -XX:MaxRAMPercentage=95.0 -jar forge-1.21-51.0.23-installer.jar -installServer


# -Xmx4G`改成实际内存值，再把启动命令换成`bash run.sh`，才能正常启动。

Fabric是这几家里最省事的：官网选版本下载，`java -Xmx2G -jar XXX.jar nogui`直接跑。

## 配置买多大：三档规则对着人数和模组数选

内存不是越大越好，买小了卡，买大了浪费。按场景分三档：

**原版或Paper小型服（3–10人）**：4核8G起。这是公开教程里反复强调的底线，低于这个数跑高版本会明显吃力。

**大型整合包（100模组以上）**：4核10G起。有教程作者用505个模组、Fabric、1.20.1的"乌托邦探险之旅3.0"实测，明确建议4核10G以上，理由是大型整合包比原版更吃性能。

**二十人左右的模组服**：内存给到6–8G比较稳，其中约4G给游戏本身，剩下的是系统开销。这个数字来自玩家社区的经验口径，不是官方标准，当作参考区间看。

CPU这块的判断比内存更容易出错。很多人盯着"几核"买，实际上Minecraft主线程基本跑在单核上，核心多不等于TPS高。同样价格下，优先选主频高的机型，核心数够用就行。

启动参数也别硬写死`-Xmx`。用`-XX:MaxRAMPercentage=95.0`让JVM自己按可用内存的95%分配，换配置时不用改脚本：


java -server -Xms128M -XX:MaxRAMPercentage=95.0 -Dfile.encoding=UTF-8 -Duser.country=CN -jar paper-1.21-50.jar


`-Dfile.encoding=UTF-8`是为了防中文乱码，`-Xms128M`设初始堆内存，小一点启动快。

怕买小了反复升级麻烦，也不想为用不上的核心多付钱，就按上面三档对号入座，从最低满足的那一档开始。

## 雨云面板服开服：从下单到朋友进服

面板服省掉的正是新手最容易卡住的三步：装Java、装控制面板、配端口映射。整套流程走下来是：

**1. 下单**

进雨云控制台，在"总览"或"云产品"里找**游戏云**，点**购买游戏云**，选**MCSM面板**，游戏类型选**纯Java环境**，Java版本选**Java 21**。然后挑机型和核数内存，付款。

**2. 进面板，上传服务端**

购买后在"我的游戏云"里能看到实例卡片，点管理进面板。先记下右侧显示的**端口号**，后面要填进配置文件。

进**文件管理** → **上传文件**，把服务端压缩包传上去。解压的时候，压缩包编码选**GBK**，不选会出现文件名乱码。解压完进文件夹，全选文件复制，回根目录粘贴。

**3. 改两个文件**

编辑`server.properties`：

- `server-port=25565` 里的25565改成面板分配给你的端口号（比如29183）。这一步不改，外网一定连不上。
- `online-mode=false` 改 `true` 就是开启正版验证。公开服建议开，只和朋友玩可以关。

编辑`启动脚本(可修改).sh`，把启动命令改成：


java -Xms128M -XX:MaxRAMPercentage=95.0 -jar server.jar


**4. 开实例，进游戏**

回控制台点**开启实例**，等日志跑完。游戏里点多人游戏 → 添加服务器，地址填平台上显示的那个，形如`xxx.rainplay.cn:29183`。

服务器第一次启动大概率会报`You need to agree to the EULA in order to run the server`。去文件管理编辑`eula.txt`，把`false`改成`true`，保存，再点开启。看到`Done`就是启动完成了。

## 开服最容易踩的六个坑

**启动报EULA错误。** `eula.txt`里的`false`没改成`true`。改完保存再点开启，不用重装。

**外网连不上，本机自己能进。** 三个方向查：`server-port`是不是还写着25565没改成面板端口；游戏内填的端口和面板显示的是否一致；协议对不对（Java版TCP，基岩版UDP，填错了防火墙放行也没用）。

**基岩版连不上。** 端口是19132不是25565，协议是UDP不是TCP。Linux下用`sudo ufw allow 19132`放行再`sudo ufw reload`。

**中文全是乱码。** 两个地方：启动命令里加`-Dfile.encoding=UTF-8`；上传压缩包解压时编码选GBK。

**模组服起不来。** 常见三种原因：模组前置没装（比如Fabric API）、模组版本和服务端版本对不上、把只该装在客户端的模组塞进了服务端。日志里会写清楚是哪个模组崩的，从最后一行往上找。

**Mohist开1.21起不来。** 它只更新到1.20.2，1.21根本没有对应版本。要么降到1.20.2，要么换成Paper（放弃模组）或Forge（放弃插件）。
